2FA einrichten

Scanne den QR-Code mit einer Authenticator-App (z. B. Google Authenticator, Authy, 1Password) oder gib den Code manuell ein.

Option A – iPhone-Passwörter (Schlüsselbund):

  1. Öffne die App „Passwörter“ auf deinem iPhone.
  2. Wähle deinen Karteikasten-Eintrag (oder lege einen neuen an) und tippe auf „Bestätigungscode einrichten“.
  3. Tippe unten auf „Konfigurationsschlüssel verwenden“.
  4. Komm hierher zurück, tippe auf „Kopieren“ unten beim Konfigurationsschlüssel, wechsle zurück zu „Passwörter“ und füge ihn ein.

Option B – separate Authenticator-App (Google Authenticator, Authy, 1Password …):

  1. Ist die App auf diesem Gerät installiert? Dann tippe einfach auf „In Authenticator-App öffnen“ unten – der Code wird automatisch eingetragen.
  2. Sonst: App öffnen, dort „Konto hinzufügen“ wählen und den QR-Code unten scannen (mit einem zweiten Gerät oder per Kamera).
